# video-helper

`video-helper` 是一个面向长录播、知识口播和课程录像的本地优先视频处理工具。

项目首先解决一个明确且高频的问题：

> 导入一整段录播，自动识别并压缩无声音区间，自动生成字幕，输出可以直接审阅或发布的粗剪视频。

项目采用分阶段演进。P0 聚焦稳定、可审计的机械性后期处理；后续阶段再逐步加入语义剪辑、知识结构化、动态图形和多模态导演能力。

## 当前最高优先级：P0

P0 的标准输入与输出：

```text
输入
├── 一整段原始录播视频
└── 可选配置文件

处理
├── 媒体检查与标准化
├── 语音/静音区间分析
├── 自动生成剪切计划
├── 自动压缩或删除无声音部分
├── 自动语音识别
├── 字幕断句与时间轴重映射
└── 低清预览与质量检查

输出
├── 粗剪视频
├── 内嵌字幕视频
├── 独立字幕文件（SRT/ASS）
├── 转录文本
├── 剪切计划
└── 处理报告
```

P0 必须支持：

- 导入常见长视频文件；
- 自动检测语音与静音区间；
- 以可配置策略删除或压缩长静音；
- 保留自然的句内停顿和切口缓冲；
- 自动生成中文字幕；
- 剪切后正确重映射字幕时间戳；
- 先生成可审阅的剪切计划，再执行渲染；
- 输出原始时间轴与成片时间轴之间的映射；
- 支持 Windows，兼容 Ubuntu 和 macOS；
- 长任务可恢复、结果可复现、中间产物可检查。

## 阶段划分

| 阶段 | 核心目标 | 典型能力 |
|---|---|---|
| **P0** | 录播自动清理 | 导入长视频、删/压静音、自动字幕、预览、导出 |
| **P1** | 可审阅的智能粗剪 | 文本式剪辑、重录/口误识别、音频增强、章节与摘要、桌面或 Web 审阅界面 |
| **P2** | 知识视频生产 | 文稿对齐、知识节点、动态图形、B-roll 规划、横竖屏与短视频版本 |
| **P3** | 多模态 AI 导演 | 画面语义理解、自动镜头决策、风格学习、素材生成与数据反馈优化 |

## P0 明确边界

P0 负责把“完整录播”处理成“完成基础粗剪和字幕的录播”。

以下能力放在后续阶段：

- 根据语义主动重组叙事；
- 自动删除跑题、重复论述或表达较差的 Take；
- 自动加入知识图、动画、素材和背景音乐；
- 从文稿直接生成完整知识视频；
- 端到端多模态 AI 导演。

## 核心设计原则

1. **本地优先**：大体积视频默认留在本机处理。
2. **决策可审计**：每次剪切都有时间区间、原因与置信度。
3. **操作可逆**：原文件只读，所有修改通过剪切计划和派生文件完成。
4. **模块可替换**：语音检测、ASR、字幕和渲染引擎通过稳定数据接口连接。
5. **长任务可恢复**：每一步独立缓存，可从失败步骤继续。
6. **跨平台一致**：Windows 为首要使用环境，同时兼容 Ubuntu 和 macOS。

## 预期使用方式

最终 CLI 形态：

```bash
video-helper run input.mp4 --preset conservative
```

也应支持分步执行：

```bash
video-helper analyze input.mp4
video-helper plan <project-dir>
video-helper preview <project-dir>
video-helper render <project-dir>
```
