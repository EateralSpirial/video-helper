# 产品规格：P0—P3

## 1. 产品定义

`video-helper` 面向以下原始素材：

- 单人知识口播；
- 课程录播；
- 屏幕录制与讲解；
- 直播回放；
- 访谈或多人录音（后续阶段）。

首要场景是：用户完成一整段录制后，希望快速得到一份已经压缩无声音区间、带有准确字幕、可以继续精修或直接发布的粗剪视频。

## 2. 优先级定义

| 优先级 | 定义 |
|---|---|
| **P0** | 构成最小可用产品；缺失任一核心环节都无法形成完整闭环 |
| **P1** | 明显提高粗剪质量、审阅效率和日常可用性 |
| **P2** | 从录播处理器扩展为知识视频生产系统 |
| **P3** | 形成能够进行多模态导演决策和自我优化的高级系统 |

# P0：录播自动清理与字幕

## P0 目标

> 输入一整段原始录播，自动检测和处理无声音区间，自动生成字幕，输出可审阅、可复现、可继续编辑的粗剪结果。

## P0-01 媒体导入

- 导入单个视频文件；
- 支持常见容器和编码，具体兼容范围由 FFmpeg 能力决定；
- 读取时长、分辨率、帧率、音视频流和旋转信息；
- 检查文件是否可解码；
- 原始文件始终只读；
- 为长视频生成低分辨率代理文件；
- 生成项目目录和项目清单；
- 对输入文件计算内容哈希，用于缓存与重复任务识别。

### P0 输出

```text
project.json
media.json
proxy.mp4
```

## P0-02 音频提取与标准化

- 从视频中提取分析音轨；
- 转换为统一采样率、声道数和 PCM 格式；
- 检测完全无音轨、损坏音轨和异常短音轨；
- 保留原始音轨信息用于最终渲染；
- 生成基础波形和响度统计。

### P0 输出

```text
analysis.wav
audio_report.json
```

## P0-03 语音与静音分析

系统需要区分两个概念：

- **静音**：音频能量低于阈值；
- **非语音**：可能包含环境声、键盘声或音乐，但没有人声。

P0 应以语音活动检测为主、响度检测为辅。

功能要求：

- 检测语音区间；
- 检测长静音区间；
- 合并距离很近的语音片段；
- 在语音片段前后保留可配置缓冲；
- 区分短停顿、句间停顿和长空白；
- 输出每个区间的起止时间、类型、检测来源和置信度；
- 支持保守、标准、激进三种预设；
- 用户可覆盖最小静音长度、保留缓冲和合并间隔。

### 剪切策略

| 区间类型 | 默认策略 |
|---|---|
| 很短的句内停顿 | 完整保留 |
| 正常句间停顿 | 完整保留或轻微压缩 |
| 较长无语音区间 | 压缩到固定时长 |
| 明显录制空白 | 删除，仅保留切口缓冲 |
| 检测置信度较低 | 标记审阅，默认保留 |

### P0 输出

```text
speech_segments.json
silence_segments.json
```

## P0-04 自动语音识别

- 对完整原始录音生成转录；
- 输出句级时间戳；
- 尽可能输出词级时间戳；
- 自动恢复中文标点；
- 保留识别置信度；
- 允许配置语言；
- 支持可选术语词表；
- 对无法可靠识别的区间进行标记；
- 保存模型、参数和运行环境信息，确保结果可追溯。

### P0 输出

```text
transcript.json
transcript.txt
transcript.md
```

## P0-05 剪切计划

剪切决策必须先以结构化文件生成，再交给渲染器执行。

每条决策至少包含：

```json
{
  "source_start": 83.42,
  "source_end": 91.16,
  "action": "compress",
  "target_duration": 0.55,
  "reason": "long_non_speech_gap",
  "confidence": 0.97
}
```

功能要求：

- 根据语音区间生成保留、压缩和删除决策；
- 自动去除开头和结尾的明显空白；
- 防止产生过短碎片；
- 防止两个切口距离过近；
- 切口前后保留可配置音频/画面缓冲；
- 输出预计成片时长和节省时长；
- 支持 `dry-run`；
- 用户可手工锁定、恢复或修改任一区间；
- 保存算法版本和配置快照。

### P0 输出

```text
cut_plan.json
cut_report.md
```

## P0-06 时间轴映射

剪掉原始时间轴中的区间后，字幕和后续元数据必须映射到新时间轴。

功能要求：

- 为每个保留片段记录原始起止时间与成片起止时间；
- 支持原始时间到成片时间的查询；
- 支持成片时间到原始时间的反向查询；
- 正确处理压缩区间；
- 使用统一精度，避免长视频累计漂移；
- 映射结果作为字幕、章节和后续编辑的唯一时间基准。

### P0 输出

```text
timeline_map.json
```

## P0-07 字幕生成

- 将原始转录映射到成片时间轴；
- 按语义、停顿和屏幕长度自动断句；
- 限制单条字幕长度；
- 避免字幕持续时间过短；
- 自动处理字幕跨越被删除区间的情况；
- 输出 SRT；
- 输出 ASS，用于样式化字幕；
- 输出结构化字幕 JSON；
- 支持将字幕烧录进视频；
- 支持输出无字幕净版；
- 允许用户在渲染前修正字幕文本。

### P0 输出

```text
subtitles.srt
subtitles.ass
subtitles.json
```

## P0-08 预览与渲染

- 生成低清快速预览；
- 渲染正式粗剪视频；
- 渲染内嵌字幕版本；
- 输出独立字幕与净版；
- 在音频切口使用短交叉淡化，减少爆音；
- 保持音画同步；
- 保持原始分辨率和帧率，除非用户显式指定；
- 支持硬件编码时自动回退到软件编码；
- 渲染中断后可继续；
- 不覆盖已有结果，除非用户显式确认或使用覆盖参数。

### P0 输出

```text
preview.mp4
rough_cut.mp4
rough_cut_subtitled.mp4
```

## P0-09 质量检查

- 检查输出文件可解码；
- 检查音画总时长一致性；
- 检查字幕时间戳递增且不越界；
- 检查异常黑帧；
- 检查异常长静音；
- 检查切口附近爆音或明显音量跳变；
- 检查时间轴累计误差；
- 对低置信度 ASR 和 VAD 区间生成审阅清单；
- 输出机器可读报告与人类可读摘要。

### P0 输出

```text
qc_report.json
qc_report.md
```

## P0-10 CLI 与任务管理

最低命令集合：

```bash
video-helper init <video>
video-helper analyze <project>
video-helper plan <project>
video-helper preview <project>
video-helper render <project>
video-helper run <video>
video-helper inspect <project>
```

通用要求：

- 每一步可独立执行；
- 每一步具备清晰日志和退出码；
- 已完成且输入未变化的步骤可复用缓存；
- 支持取消与恢复；
- 配置可由命令行、项目配置文件和预设共同决定；
- 配置优先级清晰且记录到项目中；
- Windows 路径、Unicode 文件名和空格路径必须纳入测试。

## P0 验收标准

P0 完成时，系统应满足：

1. 对一段至少 60 分钟的录播完成全流程处理；
2. 自动生成结构化静音区间、剪切计划和时间轴映射；
3. 自动生成可读中文字幕；
4. 成片字幕与语音同步，无系统性漂移；
5. 默认保守模式不会大规模截断句首或句尾；
6. 用户能够在渲染前审阅和修改剪切计划；
7. 任务中断后能够从最近完成步骤恢复；
8. 所有结果均可追溯至输入、配置和工具版本；
9. Windows 上可完成安装和运行；
10. 对同一输入和配置重复运行，剪切计划保持确定性。

# P1：可审阅的智能粗剪

## P1 目标

> 在 P0 稳定录播处理能力上，加入更高质量的语言编辑、音频增强和人工审阅工作流。

## P1 功能清单

### 文本式剪辑

- 在转录文本上删除内容并同步修改视频；
- 播放任一文本片段对应的原始画面；
- 显示每个自动决策的原因与置信度；
- 一键恢复自动删除内容；
- 锁定片段，防止后续自动流程修改；
- 比较保守、标准和激进剪辑版本。

### 语言级粗剪

- 识别明显重录；
- 识别重新起句；
- 检测连续重复语句；
- 检测常见填充词；
- 结合上下文判断是否适合删除；
- 保留完整语法和指代关系；
- 输出语义剪辑建议，由用户确认后执行。

### 音频增强

- 基础降噪；
- 响度标准化；
- 动态压缩；
- 去除低频轰鸣；
- 切口底噪连续性处理；
- 背景音乐自动 Ducking；
- 输出独立人声音轨。

### 字幕增强

- 结合术语词典和原稿纠错；
- 关键词强调；
- 逐词高亮；
- 可视化字幕模板；
- 中英混排规则；
- 字幕人工校对界面。

### 内容归纳

- 自动摘要；
- 自动章节；
- 章节时间戳；
- 核心论点；
- 标题、简介和标签候选；
- 可选的参考资料清单。

### 用户界面

- 本地 Web 或桌面审阅界面；
- 视频、波形、字幕和剪切计划联动；
- 批量接受或拒绝建议；
- 局部重新分析与局部预览。

## P1 验收标准

- 用户可在文本界面完成一次完整粗剪审阅；
- 任何自动删除均可一键恢复；
- 重录和填充词只作为建议，不在低置信度下直接删除；
- 音频增强前后响度与切口质量可通过自动报告比较；
- 自动摘要和章节均绑定成片时间轴。

# P2：知识视频生产系统

## P2 目标

> 将处理后的录播进一步转化为结构化、带有知识可视化和多平台版本的成品视频。

## P2 功能清单

### 文稿与口播对齐

- 导入 Markdown、TXT 或 DOCX 文稿；
- 对齐原稿与实际口播；
- 标记漏读、改述、增补和顺序变化；
- 使用原稿辅助字幕纠错；
- 根据原稿结构生成章节。

### 知识结构化

- 提取定义、命题、案例、结论和引用；
- 提取知识节点；
- 提取组成、因果、对比、反馈和时间顺序关系；
- 生成知识图谱 JSON；
- 将节点绑定到成片时间轴；
- 生成逐步展开的视觉叙事计划。

### 动态可视化

- 自动选择流程图、节点网络、因果循环、时间轴或对比结构；
- 根据旁白逐步显示节点和连线；
- 高亮当前概念；
- 生成可复用的程序化动画配置；
- 输出视频叠加层或完整合成视频；
- 支持统一视觉模板。

### B-roll 与素材规划

- 标记适合插入辅助画面的段落；
- 生成中英文搜索关键词；
- 搜索本地素材库；
- 记录素材来源和授权信息；
- 生成素材时间轴建议；
- 允许人工选择后自动合成。

### 多平台输出

- 横屏 16:9；
- 竖屏 9:16；
- 自动重新构图；
- 生成 30—90 秒短视频候选；
- 输出章节预告和封面文案；
- 输出无字幕、内嵌字幕和多语言字幕版本。

## P2 验收标准

- 一份完整口播可生成知识节点、关系和时间轴；
- 用户能够编辑视觉计划后重新渲染；
- 动态图形与旁白时间同步；
- 横屏和竖屏版本共享同一内容与字幕数据源；
- 素材来源可追溯。

# P3：多模态 AI 导演

## P3 目标

> 让系统综合语言、声音、画面、知识结构和历史编辑偏好，生成更接近人工导演的剪辑方案。

## P3 功能清单

### 多模态理解

- 以镜头、关键帧、音频和字幕共同理解长视频；
- 识别人脸、动作、手势、屏幕内容和图表；
- 检测视觉信息与口播是否互补或重复；
- 识别画面质量低谷和注意力低谷。

### 自动导演决策

- 决定何时保留真人画面；
- 决定何时切换到动态图形或 B-roll；
- 自动选择更自然的 Jump Cut 切口；
- 自动重组长视频叙事；
- 生成多个风格和时长版本；
- 对导演级修改保留完整解释与回滚能力。

### 生成式内容

- 自动生成缺失插图、背景和短视频素材；
- 自动生成视觉隐喻；
- 自动配乐与音效；
- 多语言翻译、配音和可选口型同步。

### 个性化与反馈

- 学习用户接受和拒绝的剪辑建议；
- 学习字幕、动画、节奏和素材偏好；
- 接入完播率、跳出点和互动数据；
- 根据发布反馈生成改进建议；
- 建立可导出、可重置的个人风格配置。

## P3 验收标准

- 系统能基于同一素材生成多个可解释的导演方案；
- 用户偏好学习结果可查看、修改和清除；
- 所有生成素材具备来源和生成参数记录；
- 发布数据只用于用户授权的项目优化；
- 高风险或低置信度导演决策必须等待人工确认。

# 3. 全阶段共同约束

## 数据安全

- 默认本地处理；
- 云端模型必须显式启用；
- 上传前显示将被发送的数据类型和范围；
- 原始文件不被修改；
- 项目可完整导出和删除。

## 可审计性

- 自动决策包含原因、来源、置信度和算法版本；
- 保留原始时间轴和成片时间轴；
- 保存每次人工修改；
- 支持重新生成相同结果。

## 性能

- 长视频分析采用流式或分块处理；
- 中间结果缓存；
- 代理视频用于预览；
- GPU 功能具备 CPU 回退路径；
- 不因单个可选模块失败而丢失已完成结果。

## 工程边界

- P0 完成前，禁止以 P2/P3 功能替代基础管线；
- 语义模型只生成建议，媒体执行由确定性时间轴引擎完成；
- 所有模块通过版本化结构化数据交换；
- UI 不得成为核心处理逻辑的唯一入口；
- CLI 和数据文件应足以完成、调试和复现整个流程。
